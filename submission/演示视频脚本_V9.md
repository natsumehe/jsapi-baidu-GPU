# 作品演示视频脚本（V9）

建议总时长 **5 分 30 秒**，使用本机浏览器实际录屏；此文档是录制脚本，不是已制作的视频。

| 时段 | 画面 / 具体操作 | 讲解重点 |
|---|---|---|
| 00:00–00:30 | 封面、技术架构图、项目仓库首页 | 目标是 JSAPI 4.0 和 WebGPU 海量空间数据融合，不是 TOS 系统 |
| 00:30–01:20 | 打开 `/`，俯视港区；推进相机，显示岸桥、Gantry、堆场与 AGV | 155 AGV、轨迹、多层箱堆、区域数据如何形成动态空间负载 |
| 01:20–02:00 | 点击 AGV、岸桥、集装箱、Gantry，展示高亮和属性 | 单车独立路线、模拟状态来源、历史轨迹，不虚称真实 GPS |
| 02:00–02:35 | 演示一车完整任务：装载→载运→Gantry 接箱→返程 | 多对多任务和安全约束；不是实际港口导航 |
| 02:35–03:15 | 打开 `/lab.html`，切换 Point/LineString/Polygon/Mixed | 按 GPU 对应图元，固定种子和对象规模 |
| 03:15–04:05 | HTTP ReadableStream 流式 100 万混合对象加载 | 增量读流、解析、上传；显示已接收字节、次数与首批可见时间 |
| 04:05–05:05 | A/B/E/C/D，若支持 WebGPU 则跑完，对比 CPU E 与 WebGPU C | WebGPU 回读和 CPU compact 必须算入端到端时延 |
| 05:05–05:30 | 展示 JSON/CSV、已知限制和 GitHub/说明书链接 | 公平、可复现、不虚构 GPU 加速 |

**录制前清单**：确保浏览器允许 WebGL、合法百度 AK、无个人凭证出现在画面中；设置合适分辨率；先做 10k 预热；为演示延迟明确标注其只改变可视化节奏。

**配音稿开头**：

> 本作品以洋山港四期为实验场景，研究海量空间对象在百度地图 JSAPI 4.0 与 WebGL、WebGPU 融合架构下的加载、计算和显示性能。系统通过真实 HTTP 数据流与 Worker 分块机制开展增量加载，用一致的点线面渲染器比较 CPU 和 WebGPU 的空间裁剪效果。码头业务用于产生复杂空间负载，系统并不控制真实港口设备。

**配音稿结尾**：

> 我们在报告中区分已完成的自动化测试、Node 数据生成测量，以及仍需浏览器实测的 GPU 指标。WebGPU 并非必然比 CPU 更快；本作品的重点是提供可解释、可验证的融合路线和公平的 A/B 对照。
